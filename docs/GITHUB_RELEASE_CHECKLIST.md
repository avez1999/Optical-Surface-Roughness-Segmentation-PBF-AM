# GitHub Release Checklist

1. Replace the placeholder repository URL and add a repository description and topics.
2. Review every image and annotation for permissions, participant identifiers, and proprietary information before publishing.
3. Confirm that `models/reference/` contains only the two intended reference checkpoints.
4. Add a license for the code and a separate data-use license if their terms differ.
5. Create a tagged GitHub release after the repository is reviewed.
6. Cite the repository URL and release tag in the manuscript.
